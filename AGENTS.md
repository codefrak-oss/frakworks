# Working agreements

- Always use a separate Git worktree for repository work. Never make task
  changes in the primary checkout.
- When asked to implement changes, carry the work through completion:
  implement, test, commit, push, and merge the PR after required checks and
  reviews pass. Do not stop at an uncommitted diff or an unmerged PR merely
  to ask whether to proceed. Pause only when genuinely blocked or user input
  is required. Never bypass branch protections or required checks.
