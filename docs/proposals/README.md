# Proposals

Design proposals: one `<name>.md` each, and often a `<name>.html` pitch page with
the same name. A proposal ticket's Smith drafts its doc here (the proposal flow,
`engine/docs/proposal.md`), and the desktop's Proposals view lists what is here on
each target repo's default branch.

The proposals written before frakworks went public were design history for
things since built, and were removed on 2026-10-15; the engine docs
(`engine/docs/`) and the code are the reference for what they described. New
proposals start here from scratch.
